Tetris game
-----------

Open `index.html` in a browser to play the Tetris game. If you're using Codespaces or a local server, serve the folder and navigate to the page.

Controls:
- Arrow Left / Right: move
- Arrow Up: rotate
- Arrow Down: soft drop
- Space: hard drop
- P: pause
